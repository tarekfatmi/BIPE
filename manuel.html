Partie 1

BIPE en général

Comprendre l'outil, son fonctionnement, ses règles.

1.1🔓 Comment se connecter

BIPE s'ouvre sur la page d'accès (f-acces.html). Deux chemins possibles : connexion ou création de compte.

Créer un compte (première fois)

  1. Sur la page d'accès, choisis l'onglet « Nouveau compte ».
  2. Renseigne : nom complet, email, code d'accès (fourni après l'achat), mot de passe (6 caractères minimum) et sa confirmation.
  3. Clique sur « Créer le compte ».
  4. BIPE vérifie que le code est valide et n'a jamais servi, puis crée le compte et te connecte automatiquement.
🔑
Le code d'accès est unique. Une fois utilisé, il est définitivement lié à ton email. Personne d'autre ne pourra l'utiliser.

Se connecter (déjà un compte)

  1. Onglet « Connexion ».
  2. Saisis ton email (ou ton nom) et ton mot de passe.
  3. Clique sur « Connexion ». Tu es redirigé vers le menu général.
⚠️
Pas de récupération de mot de passe. BIPE stocke tout en local. Si tu oublies ton mot de passe, tu ne peux pas le récupérer — il faudra recréer un compte (et perdre les données associées à l'ancien). Note-le en lieu sûr.

Se déconnecter

Depuis n'importe quelle page, ouvre le menu ⋮ en haut à droite → « Déconnexion ». Tu es renvoyé à la page d'accès.

💡
La déconnexion ne supprime aucune donnée. Elle ferme seulement la session. Tes informations restent dans le navigateur.

1.2🧭 Comment utiliser BIPE

BIPE s'organise en 7 groupes fonctionnels, accessibles depuis le menu général (index.html). Chaque groupe contient plusieurs fonctions (pages dédiées).

Navigation

  • Menu général → vue d'ensemble des 7 groupes + 4 outils transverses.
  • Carte de groupe → ouvre le hub du groupe (ex. Comptabilité).
  • Carte de fonction → ouvre la page métier (ex. Écritures, Banque).
  • Flèche ← en haut à gauche → revient à la page précédente logique.
  • Menu ⋮ → accès rapide à tous les groupes, outils, déconnexion.

Ajouter / modifier / supprimer une donnée

  1. Sur une page de fonction, clique sur le bouton doré (ex. « ＋ Nouvelle écriture »).
  2. Un panneau glisse depuis le bas (bottom sheet). Remplis les champs.
  3. Clique sur « 💾 Enregistrer » → la donnée est sauvegardée immédiatement.
  4. Pour modifier : icône ✏️ à droite de la ligne.
  5. Pour supprimer : icône 🗑 → confirmation demandée.
  6. Pour fermer sans sauver : ✕, overlay, ou touche Échap.

Filtrer et exporter

  • Filtres (chips) en haut de liste : Tous, Actifs, En retard, etc.
  • Stats en haut de page : compteurs temps réel.
  • 📤 Exporter : génère un fichier JSON téléchargeable.
💡
Chaque page est autonome. Tu peux ouvrir directement f-compta.html sans passer par le hub — l'essentiel est d'être connecté.

1.4🔄 Son approche data dynamique

BIPE n'est pas un simple formulaire. C'est un système de données interconnecté où chaque action se répercute là où c'est utile.

Le principe

  • Chaque module écrit dans une clé localStorage dédiée (ex. bipe_compta, bipe_rh).
  • Les autres pages lisent en direct ces clés pour afficher les compteurs, les listes, les statistiques.
  • Il n'y a pas de synchronisation à faire : dès qu'une donnée est enregistrée, elle est immédiatement visible partout où elle est utilisée.

Exemples de répercussions automatiques

Tu ajoutes……et automatiquement
Un membre d'équipe (RH)Il apparaît dans le sélecteur du Planning, dans les stats du hub RH, et dans la masse salariale.
Une écriture comptable (Débit/Crédit)Les totaux débit/crédit/solde se recalculent, le hub Comptabilité se met à jour.
Un compte bancaireSon solde initial est intégré au solde total du hub Comptabilité.
Un mouvement bancaireLe solde du compte concerné et le solde total sont recalculés en temps réel.
Un prospect convertiLes compteurs Nouveau / En cours / Converti / Perdu du hub Marketing sont réajustés.
Une relance marquée faiteLes compteurs À faire / En retard / Aujourd'hui / Faites se rééquilibrent.
Une sauvegardeLa date de dernière sauvegarde remonte sur le menu général (statut « il y a X jours »).
🔄
Data dynamique = pas de « rafraîchir » à faire. Tout est calculé à l'affichage. Si une donnée paraît obsolète, c'est qu'elle n'a pas été enregistrée.

1.7🚫 Les manipulations à ne pas faire

🚨
Règle d'or : sauvegarde avant toute manipulation sensible. Une donnée localStorage supprimée est définitivement perdue.

À ne jamais faire

  • Vider les données du navigateur (cache, cookies, « site data ») sans avoir exporté une sauvegarde.
  • Changer de navigateur en pensant retrouver ses données — elles sont liées au navigateur d'origine.
  • Utiliser le mode navigation privée en production : les données disparaissent à la fermeture.
  • Ouvrir BIPE depuis un autre appareil et s'attendre à voir les mêmes données — il n'y a pas de synchronisation.
  • Supprimer un compte bancaire sans vérifier les mouvements liés : ils sont supprimés en cascade.
  • Réinitialiser toutes les données (Administration) sans avoir exporté au préalable.
  • Éditer directement le localStorage via la console développeur sans savoir ce qu'on fait.
  • Modifier les fichiers HTML/JS sans sauvegarder l'original : une erreur de syntaxe bloque la page.
  • Renvoyer un même code d'accès à deux personnes : il est unique et lié à un seul email.
  • Fermer le navigateur en plein enregistrement (rare, mais préfère attendre le toast de confirmation).

Signaux d'alerte à surveiller

  • Compteurs qui n'évoluent pas après un ajout → la donnée n'a pas été enregistrée (vérifie le toast).
  • Page blanche après une modification → erreur JS (reviens à la version précédente).
  • « Non connecté » alors que tu étais connecté → session effacée (reconnecte-toi).

1.8💡 Recommandations

Rythme de sauvegarde

  • Quotidien si tu saisis des données tous les jours.
  • Hebdomadaire minimum, même en période creuse.
  • Avant toute manipulation sensible (import, reset, suppression en cascade).
  • Après une grosse session de saisie (ex. clôture comptable).

Bonnes pratiques

  • Nomme tes fichiers de sauvegarde avec la date : bipe_sauvegarde_2026-10-28.json (le nom par défaut le fait déjà).
  • Garde plusieurs versions (au moins 3 récentes) — au cas où l'une serait corrompue.
  • Stocke les sauvegardes hors du navigateur : clé USB, disque externe, dossier chiffré.
  • Utilise toujours le même navigateur pour un même espace de travail.
  • Évite les extensions navigateur qui modifient le stockage local.
  • Note ton mot de passe dans un gestionnaire de mots de passe — pas de récupération possible.

Hygiène de données

  • Un seul compte par personne — ne partage pas ton login.
  • Supprime les données obsolètes (prospects perdus, vieilles campagnes) plutôt que de les laisser s'accumuler.
  • Vérifie les compteurs des hubs : un écart signale une donnée mal saisie.
  • Fais un export avant un import — l'import écrase les clés existantes.
✅
Le réflexe BIPE : exporter → vérifier → agir. Une minute d'export évite des heures de saisie perdues.
